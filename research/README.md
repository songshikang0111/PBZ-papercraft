## 怎么查

1. 在图库筛选地区和资料类型。点图打开保留尺寸的本地文件。图下有出处，头目条目另附带时间定位的实机。
2. 先看游戏内原画底图的山脊、道路、建筑群、水系和留白，再看地标实机截图的近远关系与木石细节。点位截图与纯底图分别标注。
3. 首领查「图鉴半身」「图鉴宽幅」「实机动作」「官方设定」。两张图鉴宽窄裁图可能是同一姿态，实机截图也可能拍到同一侧。只有来源证实正侧背转面时，图库才写明该角度。
4. 普通敌人查地区图鉴。序章有两类鬼差。断魂山的 BWiki 分区和 Wikily 小怪名录均无独立普通敌人组，本版先以空营和终局角色处理。血色森林的两种兽形怪单独补录。
5. 本地 PNG、WebP、JPEG 可直接用来做选图和视觉研究。源文件统一在 `work/reference-library/images`，便于原图与生成稿分开管理。入片素材由后续独立生成的纸印、纸件和地形组成。

## 地图口径

- 悲泣溪谷、血色森林、陆家村、正道大营、梅谷湖、戏梦山庄、断魂山保存了 BWIKI 链接的游戏底图原文件，通常为 2048 × 2048。保留源文件的留白和边界。 [BWIKI 地图入口](https://wiki.biligame.com/yingzhiren/游戏地图)
- 庞镇、枷笼山从公开地图的 S-GAME 原画层瓦片拼回 2048 像素宽度的底图，另有原始游戏菜单截图。庞镇与戏梦山庄共享地貌底图，戏梦山庄的内部结构继续用演武场、戏楼、展廊、圣躯心池和灯位截图来定位。 [瓦片地图来源](https://allthings.how/phantom-blade-zero/map/mountain-of-imprisonment/) · [官方演示菜单画面来源](https://gamehq.gg/phantom-blade-zero/map)
- 序章用开场的实机画面还原驿道、马车、山崖的上下关系。已核对的正式版区域表中，序章没有单独的地图底图。 [正式版章节表](https://kungfupunk.com/zh-hans/phantom-blade-zero-chapters) · [开场马车来源](https://allthings.how/phantom-blade-zero-how-to-beat-the-hunt/)

## 头目和实机来源

- 逐条索引的是 BWIKI 正式版图鉴的 75 个名牌，已包含形态、双人同战和隐藏分支。不同资料库按战斗或形态计数，区间可出现 59 或 63 场等口径。图鉴名牌和实战区可不同。魔渊等跨区试炼按战斗实际地点写进分镜和备选。 [BWIKI 首领](https://wiki.biligame.com/yingzhiren/头目) · [pbz.gg 首领](https://pbz.gg/zh-hans/bosses/) · [首领位置对照](https://kungfupunk.com/zh-hans/bosses)

## 数据与本地复现

`catalog.json` 保存来源页、原图 URL、图种、尺寸、相对路径、SHA-256、图鉴条目和视频定位。研究图库和缓存位于 Git 忽略的 `work/`，可复用的整理脚本、分镜、索引数据进入版本控制。

图库已在本地构建。有完整图档时，以下命令可重建索引和缩略图。进到新仓库根目录执行。

```bash
uv run --with beautifulsoup4 --with requests --with pillow python research/build_index.py
```

`collect.py`、`supplement.py` 与 `landmarks.py` 记录了采集方法。若图档移走，按这三个脚本的顺序重新采集，再构建浏览页。重新拉取可能受网站后续可用性影响。
