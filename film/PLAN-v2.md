# 第二版改造计划（2026-11-24 评审）

评审意见分五条：场景要有立体地形，Boss 战要演出标志性招式，红线要成束、密集，魂要有格挡、弹反、瞬身和红蓝光提示，转场要更快。下面按条写做法，最后是执行顺序。音效清单见 `film/SFX-REQUEST.md`。

## 1. 场景：地形和建筑用 3D，细节印在贴纸上

**分工原则**：凡是决定空间感的东西都做成 3D 折纸件，包括地形起伏、高差、建筑体块和可站立的结构。凡是靠图案辨认的东西都做成贴纸，包括角色、牌匾、灯笼、旗幡、雕像、器物，以及远山的剪影层。贴纸也可以作为 3D 件的印面，比如瓦面、墙皮和岩纹。

**新增运行时件（kit.js）**

| 件 | 做法 | 用在 |
| --- | --- | --- |
| `ridge()` 等高线山体 | 5～9 层带厚度的卡纸，轮廓由噪声生成，逐层错位叠高，像切片地形模型。立起时从下往上一层层翻起 | 溪谷两侧高山、森林山坡、各章远山 |
| `backdrop()` 远景层 | 3～4 层剪影卡片立在场地后缘，颜色逐层变淡，加上雾 | 每章的天际线 |
| `channel()` 沟谷和河道 | 地面按路径切开下沉，两岸做成层叠崖壁，底部铺水面 | 溪谷峡谷溪流、陆家村水道 |
| `terrace()` 台地和坡道 | 带高度的台面，用台阶连接，角色的 y 跟着地面走 | 庞镇上坡、断魂山山路 |
| `island()` 小岛 | 不规则厚纸片高出水面，边缘做崖，上面放树和亭 | 梅谷湖 |
| `house()` 扩展 | 增加歇山、悬山、硬山、二层楼、门楼、塔、廊桥、围墙几种型；屋顶印瓦面贴纸 | 陆家村、庞镇、大营、山庄、断魂山庭院 |
| `tent()`、`palisade()` | 军帐用锥形或屋脊形折件，营栅用一排削尖木桩 | 正道大营 |
| `tree3d()` | 3D 树干，树冠由 6～12 片树叶卡片簇成，使用实例化渲染，可以密排上百棵 | 血色森林红枫、庞镇大树、各章林带 |
| `poles()` 梅花桩 | 不同高度的 3D 圆柱，顶面可站立 | 舞狮馆 |
| `well()`、`rockpile()` | 井用石圈加井架；石堆用碎岩折件，可以作为掩体 | 庞镇、戏梦山庄 |

**每章场景重做**

1. **悲泣溪谷**：两侧用 `ridge()` 做高山夹出峡谷，谷底一条溪流贯穿全场。镜头沿溪流往上游推进，三个精英分布在峡谷里的三处台地，尽头是瀑布潭，瀑布崖到 Boss 战时才立起。
2. **血色森林**：山坡用 `ridge()`，坡上密排 120 棵以上红枫（`tree3d()`），飘落红叶加量。Boss 场是开着淡蓝花的草地和挂满红线的巨树，按 Threadbound Great Tree 的样子做。
3. **陆家村**：村落密集，房屋形状各不相同，包括错落的屋顶、围墙、巷子和宗祠，村子沿水道铺开。镜头穿过村子来到开阔湖面，湖边有芦苇、栈道和泊船，最终 Boss 在这里打。
4. **庞镇**：江南水镇，密集的白墙黑瓦、河道、石桥和水阁。中段精英换成**骨婉约**，配三件标志物：井、大树，以及满天纸钱（`drift()` 新增白纸钱形状，数量很大）。之后是一段 `terrace()` 连续上坡，爬升过程要拍出高差，坡顶是舞狮馆，馆内立着 3D 梅花桩。
5. **正道大营**：成片的军帐、营栅、旗杆、校场和箭靶，远处叠层山。玉璧的场地是练武场，一端是挂金匾的厅堂。
6. **梅谷湖**：大湖加远山，近处是一串小岛（`island()`），之间有索桥或浮木。风雪刀客在湖心小岛上，岛上有沉船残骸。
7. **枷笼山**：山间牢狱，有崖壁、栈道、牢笼和红色木殿。殿里飘纸钱，有柱阵，尽头的神台上立着娘娘像。二阶段场景整体换成通红的虚拟背景，见第 2 条。
8. **戏梦山庄**：庄园楼阁、戏台、灯笼杆，石板地上有圆形石刻。
9. **断魂山**：雪山山路一路往上爬，尽头是中式庭院的门楼，左右两侧是竹林，下着雨（飘落物换成斜落的纸条雨丝和水洼涟漪）。一阶段在门楼前打，二阶段场景变成金色，见第 2 条。

## 2. Boss 战：每阶段演出 2～3 个标志性招式

每场 Boss 战从现在约 14 秒加长到约 25～30 秒，一章约 50 秒，全片约 7.5 分钟。每阶段的结构是：亮相，然后 2～3 个招式，每个招式都按"提示光 → 魂应对 → 反击"演完，最后转阶段大招或处决。

招式依据 allthings.how 各 Boss 攻略和你的描述。两者有出入时，以你的描述为准。

| 章 | 一阶段 | 二阶段 |
| --- | --- | --- |
| 追命 | 远距离锁链甩击，链子是 3D 链节，约 15 米横扫。锁链钩拽，把魂拉过去。镰刀连斩，魂逐刀格挡，火花四溅。蓝光跃下劈，魂弹反 | 翻卡变身，两条钢臂展开成六镰。大招演绎：六镰旋舞，锁链环绕全场收紧，魂红光瞬身脱出后反击 |
| 白赤练 | 快速闪身。她化成白影残像连续瞬移三次，每次出现都带一刀。月牙斩加飘带，魂格挡 | 天色转红，草地转粉，红线从天上落下。地面裂开，召唤大蛇（`serpent()` 加 3D 蛇身）缠绕后扑咬，魂瞬身躲开 |
| 沐小葵 | 远近切换。远处甩出红色剑气月牙，然后瞬间突进到近身连斩，来回切换两轮 | 先打一段，再召唤玉妖（蓝色月牙踢）和铁鬼（重拳冲撞），召唤时没有红线。三人轮流进攻 |
| 骨婉约（精英） | 井边，长袖横扫。黑雾笼罩全场，她消失后俯冲抓人。尖啸时空气扭曲，满天纸钱被吹乱 | — |
| 舞狮尊主 | 狮头冲撞，喷火柱，跃起砸地 | 跳上 3D 梅花桩，在桩间辗转腾挪，从高处扑下攻击。站在桩顶往下吐火，火流扫过地面。鹤鹤弟子围上来 |
| 玉璧 | 风：青色风刃和残影分身，从雾里突刺而出。雷：白金雷光突刺 | 闪电旋风环绕战场。一圈旋转的风柱夹着落雷，地上出现金色法阵，延迟后炸开 |
| 风雪刀客 | 冰月牙斩，地面冰刺爆发，冰环扩散 | 三连斩，三道冰封波接连推出。第三道命中魂，魂被冰封（3D 冰块包住卡片），魂破冰而出 |
| 荒行子 | 红殿里飘着纸钱，他甩动链球，掷出的链球带刃 | 变形成电锯头后**才有**电锯攻击。场景色调大变，变成通红的虚拟背景：地面、远景和天空都被染成红色，只剩剪影。锯轮冲刺 |
| 雷当 | 炮口拉出长长的红色瞄准线后开炮，扇形连发，抓住魂近身爆破 | 大招演绎：连续砸地，地面裂开起火，然后高高跃起，巨石接连落下立在地上。魂躲到石堆后面，最后一记大砸被石堆挡下 |
| 左殇 | 雨中的中式庭院门口，左右竹林，金色长剑：剑身伸长成鞭，飞剑插地，金色环斩 | 门楼震碎，碎片悬在空中，全场褪成金色。万剑归宗：漫天飞剑汇聚后齐射。金龙穿场，两人刀剑相抵，最后对决 |

新贴纸：**骨婉约**（Q 版，正在生成），魂的弹反 `deflect`、反击 `counter`、蹲躲 `crouch` 三张姿态卡（正在生成）。现有的 `parry` 卡是横刀架在胸前，直接当格挡 `guard` 用。大蛇、链节、飞剑、冰块、锯轮都用 3D 做。

## 3. 红线：一束束成把散开，密集

参考图见 `research/user-refs/red-thread-bundles-tower.png`：几百根细线几乎平行，拉成一条宽而扁的线带，从高处斜拉下来扎进地里，绷得笔直，像巨大的拉索。塔身上缠着一圈圈红线，地上散着几团松线。现在的 `threads()` 是一根根单线，太稀。

新增三种件：

- **`threadBand()` 斜拉线带**（主体）：从高处的锚点（塔顶、崖顶、树冠、屋脊）斜拉到地面的桩点。每条线带 80～200 根细线，几乎平行，宽 1.5～4 个单位。线是绷直的，没有垂度，每根线略有错位，粗细略有不同，所以看上去是有疏有密的一片红。地面落点用一根桩或一块压石固定。每章摆 3～6 条，在画面里斜切过去，成为构图线，但不能挡住 Boss 镜头。
- **`threadWrap()` 缠绕**：在柱子、树干、塔身或 Boss 武器上一圈圈缠红线，做成螺旋线圈。
- **`threadCoil()` 地面松线**：地上散落的乱线团，压平以后印在地面上，再加少量立体的线圈。
- 原来的单线 `threads()` 保留，只用来挂屋檐和木桩之间的细节。
- 线全部合并成一个几何体，几百上千根也不影响帧率。立起时线带从地面那一端"拉起"绷紧。转阶段时 Boss 身上射出线带，断的时候线带从中间崩开，两半弹回去。

## 4. 魂的战斗语言

| 动作 | 触发 | 演出 |
| --- | --- | --- |
| **格挡** | 平常接招 | 新增 `guard` 姿态卡（刀横在身前）。火花四射：橙金色火星朝外喷溅，加放射状光痕和小闪白，魂被震退半步。配金属撞击声 |
| **蓝光 → 弹反** | Boss 出招前，武器上闪出蓝白星芒 | **顿帧**：全场定格约 0.25 秒，星芒放大，画面轻微染蓝。随后魂用 `parry` 弹反，出现蓝白冲击环，Boss 失衡后仰，魂接一刀反击 |
| **红光 → 瞬身** | Boss 出招前，身上闪出红光（不可格挡） | **顿帧**加画面染红。魂碎成一团黑红纸烟散开，在 Boss 背后重新聚拢，然后背刺 |
| 受击 | 偶尔一次 | 保留现有 `hit` |
| 被冰封 | 风雪刀客 | 冰块折件包住魂，然后破冰而出 |
| 躲石堆 | 雷当 | 新增 `crouch` 姿态 |

运行时要做两件事：

- **时间重映射**：`film.hitstop(t, dur)` 让场景时钟在这段时间里停住，镜头和闪光照常走。
- **提示光**：`film.telegraph(t, actor, 'red' | 'blue')`。

姿态卡：格挡用现有的 `parry` 卡，弹反用新的 `deflect` 卡，另外新增 `counter` 和 `crouch`。瞬身不需要姿态卡，全程用纸屑来演。

## 5. 转场加快

上一章的场景折回平面后立刻衔接：

- 结尾从 3.2 秒缩到约 1.4 秒。魂跑出画面的同时纸盒折落，底色变成下一章的颜色。

## 6. 特效全部做成折纸

参照对象是溪谷那个水花冠：它由一圈有厚度、有切边、有牛皮纸背面、能投下影子的纸片组成，靠弹起和折回来动。新做的特效都照这个思路，旧特效里像普通游戏特效的那部分也一并改掉。

**通用规则**

- 只用纸件：每个特效都是带厚度、切边和背面的卡纸件，并且投影。不用加色发光，不用半透明渐变，也不用粒子光点。
- 用纸的方式动：弹出（pop-up）、折起和折回、翻面、手风琴式展开、撕开、揉团、卷曲。
- 亮度靠颜色表现：亮色纸、金箔纸、多层同心切纸叠出层次，不靠发光。
- 定格动画节奏：特效按每秒 12～15 帧步进，像手工翻拍。镜头和角色仍然是每秒 30 帧，形成对比。
- 屏幕闪白尽量少用，换成弹出的纸星芒，或者一层滑入的彩色薄纸（皱纹纸质感）。

**各类特效的纸做法**

| 特效 | 做法 |
| --- | --- |
| 火（吐火、火柱、火球） | 红、橙、黄三层火舌形切纸叠在一起，往上翻起再折倒。吐火是一串火舌卡沿直线手风琴式展开；火柱是纸条卷成的螺旋筒往上旋；火球是揉皱的纸团 |
| 水 | 保留水花冠。瀑布改成竖向纸条循环滚动，涟漪用锯齿切边的纸环 |
| 冰（冰封波、冰刺、冰封） | 折纸多面体冰晶（棱锥和棱柱）沿地面接连弹起。冰封是一个折纸多面体罩住魂，破冰时各面翻飞散开 |
| 雷电 | 折成锯齿的纸带，从天上"啪"地展开插地，落点弹出一张星芒切纸。闪电旋风是一圈螺旋纸带加锯齿纸条绕场旋转 |
| 风 | 卷纸（衍纸螺旋条）一边翻卷一边飞过 |
| 刀光、剑气 | 刀光是有厚度的月牙形切纸带，边缘带锯齿。剑气是一张飞出去的月牙纸卡，会翻转 |
| 格挡火花 | 金箔小三角纸屑和细纸条朝外喷射，中心弹出一张放射状星芒切纸 |
| 红光、蓝光提示 | 兵器上弹出一张红色或蓝色的星芒折纸，同时滑入一层同色薄纸，然后顿帧 |
| 瞬身黑红烟 | 黑色和红色的撕边纸屑卷成一团散开，在 Boss 背后重新聚成魂 |
| 黑雾（骨婉约） | 几层撕边的黑色薄纸横向滑过全场 |
| 纸钱 | 真正的方孔纸钱切片，满天飘落 |
| 锁链（追命） | 纸环串成的纸链，像节日纸链装饰那样 |
| 大蛇（白赤练） | 手风琴折的纸蛇，一节一节的蛇身卡，蛇头单独做成折件 |
| 爆炸、砸地 | 弹出式放射花瓣切纸往外展开，同时飞出揉皱的纸团和碎纸 |
| 冲击环 | 锯齿切边的纸环 |
| 落石（雷当） | 折纸多面体岩块，落地后弹一下立住 |
| 金光、万剑、金龙（左殇） | 金箔折纸剑，金色同心放射切纸层层弹开。金龙做成舞龙式的分节纸龙 |
| 红色虚拟背景（荒行子） | 场景各层依次翻面，背面印着红色 |
| 处决墨条 | 撕边纸条横扫过画面 |

## 执行顺序

1. 运行时：地形件、建筑型、`tree3d`、`threadBundle`、顿帧和提示光、格挡火花、瞬身、快转场。补魂的新姿态卡和骨婉约贴纸。
2. **先做悲泣溪谷样片**，包括峡谷地形、追命两阶段全套招式、红线束和新转场，给你看过再铺开。
3. 按 2～9 章顺序逐章重做，每章出静帧核查后再渲染。
4. 音效到位以后改 `sfx.py` 和 `mix.py`，接入新的事件类型，然后拼全片。
