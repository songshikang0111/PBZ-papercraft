# 章节制作 SOP

每章按同一流程制作。规则来自悲泣溪谷样片的评审，后续章节都要遵守。

## 1. 素材

1. 在 `film/jobs/build_jobs.py` 里给本章列 7～10 张贴纸，参考图按地标关键词从 `research/catalog.json` 自动选取。写完后运行该脚本生成任务文件，再执行 `python film/tools/gen.py film/jobs/<章>.json`。
2. 用 `film/tools/sheet.py` 拼图检查。贴纸只负责卡面印刷，结构、光影和红线都在 3D 里做。
3. 同类元素不要堆太多。例如溪谷的铁管最初放了好几根，显得突兀，后来只留一根，其余换成石碑、红线木桩和碎木板。元素从实机截图里挑，种类要多。
4. 原作里没有的几何道具不放。例如残钢脚下那块方台就去掉了。简单房屋可以用 `house()` 做成 3D 折盒，四周拉红线。

## 2. 场景

1. **红线**：每章都要有，这是游戏的视觉母题。用 `threads()` 做 3D 红线，挂在屋檐、树枝、木桩、Boss 身上，卡片立起时线也跟着绷起来。阶段转换时可以让红线"射出"（参数 `t0`），并在需要时剪断（参数 `t1`）。
2. **飘落物**：每章都要有，用 `drift()`。各章对应：溪谷是彼岸花瓣，森林是红枫叶，陆家村是金色芦絮，庞镇和大营是火星，梅谷湖是雾和雪，枷笼山是雾和红布屑，山庄是灯火余烬和花瓣，断魂山是大雪。
3. **分批立起**：开场只立 `world` 组。Boss 战场地放进 `arena` 组，到 Boss 战前才立起；在此之前完全隐藏，不会平铺在地上露出来。精英和 Boss 在各自登场时刻之前也是隐藏的。

## 3. 镜头

1. 每个镜头都要检查遮挡。前景不能有大卡片挡住主体：树、山崖、红线木桩都要避开镜头连线。
2. 精英镜头距离 28～34，俯角 38～44。Boss 战距离 30～38，俯角 30～34；转阶段特写距离 22～26，俯角 28～29。
3. 渲染逐个时间点的静帧检查（每个时间点开一次新页面），重点看名牌、遮挡、特效和变身。

## 4. 转场（往上走，第三版）

全片一路往上推进，魂只往上走。

1. 开场：从本章底色的空白纸面开始，魂从画面下边缘跑进来，往上跑到落脚点，然后折下消失，地区立起，竖幅标题折下（`intro()`）。
2. 结尾：Boss 倒下、「斩」字印章盖下后，魂往上跑，从画面上方消失；镜头只慢慢跟一小段，场景折回纸面，纸色渐变成下一章的底色（`outro()`，颜色见 `GROUNDS`）。
3. 两章衔接处的镜头参数和魂在画面中的位置一致，拼接时再加 0.6 秒交叉淡化，抹平各章调色的差异。

## 5. 渲染与成片

1. 用 `film/tools/queue.sh <章...>` 按顺序渲染逐帧画面、无声 MP4、音效 WAV 和带音效预览。
2. 用 `film/tools/assemble.py` 把各章拼成全片和整条音效轨。配乐由你后期另行铺入。

## 第二版补充（2026-11-24）

详见 [PLAN-v2.md](PLAN-v2.md)。以下是每章都要遵守的做法。

1. **地形**：场地沿纸面纵深推进，镜头一路往上游走，依次经过各个精英，最后到达 Boss 场。两侧是隧道书式的崖壁（`terrain.wings()`），远处是山脉剪影（`terrain.range()`）。抬高的场地用平台（`island()`）。精英的视线楔形区内不放高物件，判断函数见各章的 `inSight()`。
2. **分组**：Boss 场前方那段景物放进 `field` 组，Boss 场立起时折下并离场，不挡决斗镜头。`void` 组用作二阶段换场，例如枷笼山的红色空间、断魂山的金色空间。
3. **红线**：用 `threadBand()` 从崖顶斜拉到崖脚，沿着岩壁走，不要横穿镜头。
4. **战斗语言**：每个招式按"提示（`B.tell` 红或蓝，带顿帧）→ 应对（`guard`、`deflect`、`shadowstep`）→ 反击（`counter`）"的顺序写。两张角色卡至少间隔 4.5 个单位。卡片较宽的 Boss 要守住场地一侧。
5. **特效**：只用 `fx.js` 里的纸件。场地高于地面时，用 `beats(..., { y0 })` 抬高特效，并把各特效的 `at[1]` 或 `y` 设为相同高度。
6. **转场**：开场约 1 秒，结尾约 1.4 秒。最后一章接 `GROUNDS.end`。
7. **音效**：新事件类型在 `sfx.py` 里合成。真实素材按 [SFX-REQUEST.md](SFX-REQUEST.md) 的文件名放进 `work/film/audio/common/sfx/`，会自动替换合成音。配乐和人声的时间点由 `mix.py` 从事件日志推出。

## 第三版补充（2026-11-25）

1. **红蓝光**：`B.tell` 用 `fx.glint()`，是游戏里那种长横光带穿过刀上一颗亮星的效果，用五层叠起的梭形纸条和星形剪纸做成。光带在顿帧期间照常按真实时间动（`live` 特效）。红光表示不可格挡，魂瞬身；蓝光表示可弹反。
2. **转场往上走**：见第 4 节。
3. **台词**：Boss 和中 Boss 的每句台词都在场景脚本末尾的 voices 块里用 `film.voice(t, file, { seg, cap })` 排时间，对准招式，并且只放在它所属的阶段（例如沐小葵的“玉妖、铁鬼，听命！”只在二阶段护卫出场前）。`mix.py` 照排好的时间放：台词不挪位置，发声会避开台词，避不开就丢掉。缺的文件会在 `mix.py --probe` 里标成 MISSING，补的清单在 SFX-REQUEST 的 D 节。只导出事件表、不渲染画面：`render.py <章> events`。
4. **中 Boss 不加战斗**：只登场、亮名牌、说一句台词（例如骨婉约）。
5. **建筑**：`common/build.js` 里有两种 3D 纸模。`jiangnanHouse` 有两种：庞镇的白墙黑瓦马头墙房子，以及 `horse: false` 时的木板屋，可以加吊脚（陆家村、游龙的水寨）。`tower` 是会倾斜的多层楼阁（烟千岁身后那座）。村镇的房子要排得密，并且高低错落。

## 第四版补充（2026-11-25，见 [PLAN-v3.md](PLAN-v3.md)）

1. **台词说完整**：整句台词（kind 为 line）不设时长上限。场景开头用 `film.vlen(file, seg)` 读取台词的实际时长（数据在 `common/vo-lengths.json`，用 `python film/tools/mix.py --lengths` 重新生成），按这个时长排精英节拍。中 Boss 的台词在卡片开始立起时就开口。`mix.py --probe` 会报 `OVERLAP`（两句台词重叠）和 `SPILL`（台词越过章末），有任何一条都不能出片。
2. **中 Boss 展示**：每个中 Boss 只演一个标志性场面，持续 3～6 秒，期间魂不出场。用 `hero.hideBetween(t0, t1)` 把魂从开场藏到 Boss 场（时间是绝对时间）。`elite(..., { move: 'none', dur })` 只负责立起和名牌，招式在场景里自己写。全片同一类动作最多用两次。
3. **时间平移**：Boss 战沿用 v3 的时间，只在前面调用 `film.shift(D)`，之后注册的所有东西都会整体后移 D 秒，包括 cue、声音、台词、角色关键帧、镜头关键帧、group 立起、叠层和顿帧。镜头分两次调用 `film.camera`：精英段在 shift 之前调用，Boss 段在之后调用。场景里自己写的 `film.every` 如果拿绝对时间做比较，要手动加上 D。
4. **镜头**：每场 Boss 战至少有三种景别。Boss 落地用低机位仰拍（pitch 6～9），红光提示时切近景，击杀用过肩镜头（yaw 约 40）。
5. **标题和「斩」**：章节标题自动使用游戏书法字（`kit.js` 的 `TITLE_ART`，放在右上角或正中，用墨迹刷出），「斩」自动使用游戏原版红字。
6. **片头和片尾**：分别是 `chapters/00-opening` 和 `chapters/10-ending`，标题卡在 `common/titlecard.js`。两段配乐是预留位：`work/film/audio/common/music/title_theme.wav` 和 `ending_theme.wav`，文件到位后会自动替换。
